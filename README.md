# My Portfolio Website

This is my personal portfolio website made using HTML and CSS. It tells about me, my education, skills, projects, hobbies and achievements.

## Sections

- About Me
- Education
- Skills
- Projects
- Hobbies
- Achievements
- Contact Me

## Technologies Used

- HTML
- CSS

## Files

```
portfolio/
├── index.html    (the main page)
├── style.css     (the design and colours)
└── README.md     (this file)
```

## How to Run

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Double click `index.html` to open it in a browser.

## How to Change It

- Open `index.html` in any text editor (like VS Code) and replace "Your Name", education, skills, projects and contact details with your own.
- Open `style.css` to change the colours (for example, replace `purple` with `blue` or `green`).
